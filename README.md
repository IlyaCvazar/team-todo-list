Веб-приложение для управления задачами команды, разработанное в рамках учебного проекта.  
**Улучшенная версия** с современным дизайном и дополнительными функциями.

## 🎯 Цель проекта

Получить практические навыки командной разработки программного обеспечения с использованием Git, GitHub и базовых веб-технологий.

## ✨ Функциональность

- ✅ Добавление новых задач с указанием исполнителя
- ✅ Отметка задач как выполненных (чекбокс)
- ✅ Удаление задачи с подтверждением
- ✅ Фильтрация задач: Все / Активные / Выполненные
- ✅ Счётчик общего количества и активных задач
- ✅ **Сохранение всех задач в localStorage** (данные не теряются при перезагрузке)
- ✅ **Редактирование задачи** (текст и исполнитель) — по кнопке ✏️
- ✅ **Отмена последнего действия** (↩ Undo) — можно откатить изменение
- ✅ Современный отзывчивый дизайн, приятный глазу

## 🛠️ Технологии

- HTML5 (семантическая вёрстка)
- CSS3 (Flexbox, анимации, адаптивность, backdrop-filter)
- JavaScript (Vanilla JS, работа с localStorage, стек истории)
- Git & GitHub (ветки, Pull Request, слияние)

## 🚀 Как запустить проект

1. Клонируйте репозиторий:
```bash
git clone https://github.com/IlyaCvazar/team-todo-list.git
```
2. Перейдите в папку:
```bash
cd team-todo-list
```
3. Откройте `index.html` в браузере (двойным щелчком или через Live Server).

## 📖 Как использовать

1. Введите текст задачи и исполнителя, нажмите «Добавить».
2. Чтобы отметить задачу выполненной — щёлкните чекбокс.
3. Кнопка 🗑️ удаляет задачу (с подтверждением).
4. Кнопка ✏️ открывает режим редактирования: измените текст или исполнителя и нажмите «Сохранить».
5. Фильтры «Все», «Активные», «Выполненные» позволяют быстро находить нужные задачи.
6. Кнопка **↩ Отменить** отменяет последнее действие (добавление, удаление, изменение статуса, редактирование). Активна, если есть что отменять.
