# 📋 Командный список задач

Веб-приложение для управления задачами команды, разработанное в рамках учебного проекта.

## 👥 Команда разработчиков

- **Тимлид / Backend / Frontend / Тестировщик / Документатор:** [Околелов И.А.]

## 🎯 Цель проекта

Получить практические навыки командной разработки программного обеспечения с использованием Git, GitHub и базовых веб-технологий.

## ✨ Функциональность

- ✅ Добавление новых задач с указанием исполнителя
- ✅ Отметка задач как выполненных
- ✅ Удаление задач
- ✅ Фильтрация задач (все/активные/выполненные)
- ✅ Счётчик общего количества задач и активных задач
- ✅ Сохранение задач в localStorage (данные не теряются при перезагрузке)

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Git & GitHub

## 🚀 Как запустить проект

1. Клонируйте репозиторий:
```bash
git clone https://github.com/IlyaCvazar/team-todo-list.git

2. Перейдите в папку проекта:
cd team-todo-list

3. Откройте файл index.html в браузере.

📖 Как использовать
Введите текст задачи в первое поле

Укажите исполнителя во второе поле

Нажмите кнопку "Добавить"

Используйте чекбокс для отметки задачи как выполненной

Нажмите "Удалить" для удаления задачи

team-todo-list/
├── index.html       # Главная страница
├── style.css        # Стили приложения
├── script.js        # Логика приложения
├── README.md        # Документация
└── TESTING.md       # План тестирования
